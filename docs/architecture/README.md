# RENOVA-AI System Architecture

## Core Components
1. **Frontend**: React 18, Vite, TypeScript, Tailwind CSS, Lucide, i18n
2. **Vision Engine**: YOLOv8 ONNX real-time browser & server inference
3. **IoT Hub**: ESP32 MQTT/WebSocket sensor stream
4. **Circular Economy Engine**: B2B recycled marketplace & dynamic ROI calculation
