# RENOVA-AI 🌿🤖

> Enterprise Autonomous Waste Intelligence & Circular Economy SaaS Platform

## Architecture & Overview
RENOVA-AI is a next-generation AI and IoT driven circular economy platform built for enterprise waste management, real-time material classification (YOLOv8 vision inference), smart bin telemetry (ESP32 IoT engine), and multi-stakeholder dashboards.

### Features
- **3D Interactive Hero & Earth Visualizer** powered by Three.js & Lucide
- **AI Computer Vision Pipeline**: Real-time YOLO waste material classification
- **IoT Sensor Telemetry Engine**: Live WebSocket simulator for ultrasonic fill level, weight, and automated sorting gates
- **Circular Marketplace**: B2B recycled material catalog with automated invoicing
- **Multi-Stakeholder Portals**: Customized dashboards for Hotels, Restaurants, Vendors, Farmers, Contractors, Delivery Fleet, and Super Admins
- **Bilingual i18n**: Native English & Tamil language switching

## Setup Instructions

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
